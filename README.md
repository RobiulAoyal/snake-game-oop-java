# 🐍 Snake Game 

A classic **desktop Snake game** built using **Java Swing** and **Object-Oriented Programming (OOP)** principles.  
The game features smooth movement, apple collection, scoring system, and collision detection.

---

## 🎮 Features

- 🧱 Grid-based movement system  
- 🍎 Random apple generation  
- 📈 Score tracking system  
- ⌨️ Arrow key controls  
- 💥 Collision detection (walls & self)  
- ⚡ Real-time gameplay using Java Timer  

---

## 🧠 OOP Concepts Used

- Encapsulation → Game state managed inside classes  
- Inheritance → `Apple` extends `GameObject`  
- Abstraction → `GameObject` abstract class  
- Polymorphism → `draw(Graphics g)` overridden in child classes  
- Composition → GamePanel manages all game components  

---

## 🏗️ Project Structure

SnakeGame/
- GameFrame.java
- GamePanel.java
- GameObject.java
- Apple.java
- SnakeGame.java
---

## 📦 Requirements

- ☕ Java JDK 8 or higher  
- 🖥️ Any Java IDE (Eclipse / IntelliJ / VS Code)  
- 📚 Built using Java Swing (no external libraries required)
